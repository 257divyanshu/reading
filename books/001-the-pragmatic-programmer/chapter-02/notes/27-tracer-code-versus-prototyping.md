### 👉 **Prototyping**

* Build quick, partial solutions
* Used to **explore ideas (UI, algorithms, etc.)**
* Code is **thrown away**

---

### 👉 **Tracer Code**

* Build a minimal **end-to-end working system**
* Used to **validate architecture + interactions**
* Code is **kept and extended into final product**

---

## 🔹 Core difference (1-liner)

👉 **Prototype = explore & discard**
👉 **Tracer code = build & evolve into production**

---

## 🔹 Extra clarity

👉 Prototype answers:

> “Will this idea work?”

👉 Tracer code answers:

> “Does the whole system work together?”

---

## 🔹 Final takeaway

👉 **Prototype before you know what to build; tracer code after you know what to build but need to connect everything.**
